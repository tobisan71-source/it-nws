# IT NWS Website

Marketing site for **IT NWS** (IT Nordwestschweiz) — Next.js App Router, TypeScript, Tailwind CSS.

## Pages (v1)

- `/` Home
- `/leistungen`
- `/kmu`
- `/privatkunden`
- `/kontakt` (contact + appointment modes)
- `/impressum`, `/datenschutz` (legal stubs)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
